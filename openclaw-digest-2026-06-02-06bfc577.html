AI 安全 网络攻击

首次 LLM Agent 自主网络攻击被记录：不到 1 小时窃取 AWS 数据库

Sysdig 记录了首次 LLM Agent 完全自主执行后渗透攻击：利用 CVE-2026-48710（"BadHost"）Starlette Host 头注入漏洞，自主完成漏洞发现→代码生成→提权→数据窃取全链路。

影响范围：数百万 AI Agent 服务器、FastAPI、vLLM、LiteLLM、MCP 服务器。全程无人工干预，总耗时不到 1 小时。补丁已发布。
